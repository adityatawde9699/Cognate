# Cognate v3.1.0-rc.7

Production-stabilization candidate for the R23–R26 work. This is a prerelease; installed Windows/macOS acceptance and the remaining live-service checks are still open.

## Changes

- Remote AI calls show the destination, model, instructions and complete task payload before sending. Requests can be cancelled; local models remain on-device. Provider output is size/schema/date/ID checked as a whole, malformed advice does not alter the current plan, and accepted estimates retain provider/model/local/time provenance in the atomic task history.
- Native AI requests reject unsafe endpoints and redirects, bound time and response size, cancel active requests, and redact provider error bodies. Offline task capture continues through the deterministic parser.
- Desktop startup restores an existing window on second launch; tray identity and Show behavior are explicit. Updates require a verified pre-update backup and drain database writes before signed installation. Local diagnostics report bounded categories/timing and expose sync health without retaining task data, URLs, prompts or error strings.
- Added a reproducible TypeScript planner/50k-operation benchmark and a real HTTP relay persistence/restart benchmark with retained baseline reports and provisional CI regression ceilings.
- Added adversarial/generated Rust/TypeScript planner parity, six historical SQLite schema/reopen/rollback fixtures, Linux isolated Tauri WebDriver recovery smoke, relay hard-kill/replay verification, and Windows/macOS native Rust contract jobs.

## Verification

Local checks: typecheck, 322 Vitest tests across 47 files, 30 Chromium tests, two production PWA tests, 272 Rust/TypeScript parity cases, 44 desktop Rust tests, desktop Clippy with warnings denied, 16 relay tests, relay Clippy, nine isolated Linux native WebDriver checks, measured task/operation/relay regression budgets, production build isolation and release metadata validation.

The tagged CI workflow adds Linux WebView/keychain/recovery smoke and Windows/macOS native contract jobs. Those jobs must pass before this candidate is published. The Linux smoke build uses `com.cognate.smoke` with temporary OS data roots; it must not be installed as production Cognate.

## Remaining acceptance

Windows/macOS installed webview, tray, notification, keychain and updater/data-restore checks remain open. Native notification click behavior, live AI providers/OAuth, deployed multi-device relay faults/public load, mobile PWA eviction, native/browser startup performance, complete accessibility acceptance and production web deployment remain outside this candidate's verified evidence. Consult [the production roadmap](PRODUCTION_ROADMAP.md) and [native acceptance matrix](NATIVE_ACCEPTANCE.md). Stable v3.0.3 remains the latest automatic-update release.
