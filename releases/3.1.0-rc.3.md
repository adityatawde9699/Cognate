# Cognate v3.1.0-rc.3

Production stabilization release candidate covering the R01–R19 implementation work. This is a prerelease; production acceptance remains incomplete.

## Changes

- Keep relay poll admission compatible with current Rust linting without changing capacity limits.
- Fix Auto-plan startup race by awaiting database initialization before reading the planning snapshot. Supersedes the unpublished first candidate whose CI exposed this issue.

- Atomic task, project, plan and history writes in SQLite and IndexedDB; guarded imports, history audits and explicit repair.
- Verified WAL-safe backups, retained browser migration snapshots and encrypted identity/data recovery kits.
- Calendar recurrence, timezones, DST, detached exceptions and freshness/coverage warnings; atomic reflow with persisted rationale.
- Signed immutable sync batches, durable outbox/cursors, actor verification, encrypted browser secrets and fail-closed desktop keychain storage.
- Signed project invitations and owner-controlled read-key epoch rotation.
- Durable bounded relay journal, admission limits, health/metrics and TLS/systemd deployment templates.
- Loopback OAuth callback and token lifecycle guards; complete offline PWA precache and safe update/rollback behavior.

## Before upgrading

Export a local backup and retain your recovery kit. The v2 sync journal requires a compatible relay; legacy live blobs and invitations are not silently migrated. Workspace key/endpoint changes are blocked where signed history needs migration. Share rotation requires new invitations; offline edits across rotation still need a transfer policy.

This prerelease does not replace the stable release used by automatic updates. Install it explicitly to evaluate it. Updater artifacts are signed; OS signing/notarization remains outside this release configuration.

## Validation and remaining work

Local checks passed: 283 JavaScript tests, 24 browser tests, 2 production PWA tests, 53 Rust tests, typecheck, builds, artifact isolation and Clippy. The tagged workflow repeats blocking checks before packaging Linux, macOS and Windows installers.

Live Google/Microsoft OAuth, installed OS/keychain/callback and mobile tests, journal compaction, legacy sync migration and public staging fault/load tests remain pending. See [the production roadmap](https://github.com/adityatawde9699/Cognate/blob/v3.1.0-rc.3/docs/PRODUCTION_ROADMAP.md) for the full ledger. R20–R28 remain open.
